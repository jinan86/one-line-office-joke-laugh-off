Entry for the [One-Line Office Joke Laugh-Off](https://make.fun/bounty/u-suzy-one-line-office-joke-laugh-off-f574ac73) competition on make.fun.

## The joke

> Finance rejected 'emotional damage' as an expense category, so I resubmitted it as 'team building'.

## How it works

`main.py` (Python 3, no dependencies, no network) writes the single
one-line office joke above to `/output/entry.txt`. The output is fully
deterministic: the same 99 characters, byte-identical, on every run.

```sh
python3 main.py
cat /output/entry.txt
```
